# 本地材料编辑器

Windows 双击工作区 `打开Dashboard.cmd`，macOS 双击 `打开Dashboard.command`。同一窗口会启动并监测 Dashboard（`127.0.0.1:8765`）和材料编辑器（`127.0.0.1:8766`），并在两个服务就绪后用系统默认浏览器打开看板；从看板进入材料编辑器。它只读取 `个人资料/CV/` 中已生成的岗位目录，不访问招聘网站或云服务；首次使用由 Agent 按 [安装指南](../INSTALL.md) 安装依赖并初始化工作区。Mac 工作区需在 Mac 上运行安装器，以生成可双击的启动文件。

选择岗位目录及 CV 或动机信，单击页面组件进行选择，拖动以移动，拖动四角以调整宽高；中间边缘按移动处理，避免误改高度。双击文字直接修改，也可以在右侧设置文字、偏移、尺寸、字号、颜色和透明度；图片可从本机选择 PNG、JPEG 或 WebP。可选择标题、文本块、图片、分隔线和其他 HTML 区块。

打开材料后，左侧“添加元素”可插入文本框、色块、分隔线或图片；图片限 PNG、JPEG、WebP，最大 1 MB。元素在当前画布可见区域内出现并自动选中，可沿用右侧属性和拖动操作；“删除新增元素”移除选中的新增内容。颜色窗提供二维调色盘、色相／饱和度／亮度和十六进制输入。新增及调色均先保留在草稿中，“取消”恢复当前材料最后保存的版本，“保存并生成 PDF”将新增内容一并写入材料和 PDF。

点击“保存并生成 PDF”后，编辑器先在临时文件中重建 PDF 并检查页面是否溢出。成功后更新该岗位目录的 HTML、原 PDF 和预览图；旧版 HTML/PDF 保存在 `work/editor-history/`。失败时保留当前正式文件。编辑结果的 `work/*-editor-review.json` 标记为待视觉审查；修改文字还须重新核对唯一事实库及岗位 claim-map。已有的材料快照会因 PDF 改变而失效，后续无人值守投递必须由 Agent 重新审查材料并记录依据。

编辑器处理现有 HTML 的局部位置和样式，不提供旧版九套模板画廊。移动组件使用相对原位置的位移，可能造成重叠；保存前检查整页版面。

窄窗口中，材料选择区移至画布上方，属性面板依宽度移到右侧或下方，画布自动缩放。未选岗位目录时“打开材料”不可用。右侧文字输入立即更新画布；有未保存修改时，切换材料、刷新或离开页面会提示。保存期间暂停编辑，失败后保留画布修改以便重试。

持久工作区中，有未保存修改时点击看板会提供“返回编辑 / 保留修改并切换 / 保存后切换”。保留后返回仍是同一份草稿；打开其他材料仍明确提示放弃当前修改。单独打开编辑器页面时，离开会丢失草稿，使用相应的放弃提示。保存失败保留修改并停留编辑器。属性面板每对字段共享标签行和输入行，最长译文换行也不使输入框错位。

PDF 实际保存成功后，保存按钮播放一次不拦截输入的粒子反馈；成功提示附带实际 PDF 绝对路径。失败时不播放成功反馈，继续保留未保存修改。
