# 本地材料编辑器

Windows 双击工作区 `打开Dashboard.cmd`，macOS 双击 `打开Dashboard.command`。同一窗口会启动并监测 Dashboard（`127.0.0.1:8765`）和材料编辑器（`127.0.0.1:8766`），并在两个服务就绪后用系统默认浏览器打开看板；从看板进入材料编辑器。它只读取 `个人资料/CV/` 中已生成的岗位目录，不访问招聘网站或云服务；首次安装依赖时需运行项目的 `npm ci`。Mac 工作区需在 Mac 上运行或重跑 `init --workspace PATH`，以生成可双击的启动文件。

选择岗位目录及 CV 或动机信，单击页面组件进行选择，拖动以移动，拖动边缘以调整宽高。双击文字直接修改，也可以在右侧设置文字、偏移、尺寸、字号、颜色和透明度；图片可从本机选择 PNG、JPEG 或 WebP。可选择标题、文本块、图片、分隔线和其他 HTML 区块。

点击“保存并生成 PDF”后，编辑器先在临时文件中重建 PDF 并检查页面是否溢出。成功后更新该岗位目录的 HTML、原 PDF 和预览图；旧版 HTML/PDF 保存在 `work/editor-history/`。失败时保留当前正式文件。编辑结果的 `work/*-editor-review.json` 标记为待视觉审查；修改文字还须重新核对唯一事实库及岗位 claim-map。已有的材料快照会因 PDF 改变而失效，后续无人值守投递必须由 Agent 重新审查材料并记录依据。

编辑器处理现有 HTML 的局部位置和样式，不提供旧版九套模板画廊。移动组件使用相对原位置的位移，可能造成重叠；保存前检查整页版面。
