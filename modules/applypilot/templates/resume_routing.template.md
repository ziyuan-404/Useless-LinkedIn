# Resume Routing Template

## Strategy

Choose one:

- Precision tailoring: apply to fewer high-fit jobs and tailor materials.
- Volume routing: use stable resume variants and prioritize speed.

Selected strategy:

If unsure, start with Volume. Promote a specific high-fit role to Precision when it is worth tailoring.

## Resume File Format

Before selecting Precision, provide an editable resume source if possible.

| Format | Best use | Tailoring support |
|---|---|---|
| DOCX | Source resume and tailored outputs | Best |
| Markdown | Source resume and agent editing | Best |
| Google Docs export | Source resume and tailored outputs | Good |
| Plain text | Rebuilding or drafting | Good |
| PDF | Uploading to applications and reviewing | Weak for direct editing |

PDF-only note:

- A PDF can be used for applications.
- A PDF can be reviewed for fit.
- A PDF is usually not the best source for precise edits.
- If only PDF is available, ask the agent to create an editable draft before tailoring.

## Tailoring Rules

Tailor only when:

- Fit score or qualitative fit is high.
- Company or role is high priority.
- The user explicitly asks for a custom resume.
- The application requires a custom answer or cover letter.

Do not tailor when:

- Role is low fit.
- Form is long and conversion probability is low.
- Stable resume variant is already a strong match.

PDF-only policy:

- The agent may review and suggest edits.
- The agent may draft a new editable version if the user approves.
- The agent should not promise reliable in-place PDF editing.

Versioning rule:

- Never overwrite the source resume.
- Save tailored resumes as new versions.
- Record the tailored file path in the dashboard.

Truthfulness rule:

- Treat summary, bullets, keywords, metrics, tools, and domain framing as suggestions until the user confirms they are true.
- Reorder, emphasize, tighten, and keyword-align only after truthfulness is confirmed.
- Do not invent experience, metrics, employers, degrees, tools, dates, or authorization.
