# CV 制作规范

生成、修改或审核 CV 时必须读取本文件。它约束内容选择、页面结构、字体、照片、间距、输出格式和视觉验收。候选人事实仍只来自 `WORKSPACE_ROOT/个人资料/profile/`；本文件不提供或补造人物事实。

工作区的 `个人资料/template/resume.html` 和 `个人资料/template/format-default.md` 是当前确认的视觉母版。生成岗位版时只替换内容，不重新设计母版，不改变已确认的栏宽、颜色、照片规则和信息层级。用户明确指定新模板时，先更新母版和本规范，再生成材料。

## 一、硬性成品要求

| 项目 | 规范 |
|---|---|
| 页数 | 默认且目标为 **1 页 A4**。只有用户明确同意且一页无法真实呈现关键经历时才使用 2 页。 |
| 页面 | A4 竖版，`210 mm × 297 mm`，页面外边距为 `0`，由左右栏内部 padding 控制安全区。 |
| 输出 | UTF-8 HTML 和 PDF；PDF 必须启用背景色，保持可选择文本，不栅格化整页。 |
| 字体 | Arial；不可用时依次使用 Helvetica、sans-serif。不得逐岗位临时更换字体。 |
| 正文字号 | 默认 `10 pt`；任何正文、日期、地点和 bullet 不得低于 `9 pt`。不得靠缩到 7–8 pt 强塞一页。 |
| 页面利用 | 右栏有效高度应使用约 `85%–96%`；底部可以保留呼吸空间，但不得出现接近三分之一页的无意义空白。不得为填满页面增加无证据内容。 |
| 溢出 | 不允许裁切、重叠、跨页孤行、横向滚动或超出 A4。 |
| 路线一致 | `Alternance`、`Stage` 或其他合同路线只能选一条；标题、PROFIL 右上角、Disponibilité、正文和动机信必须一致。 |
| 真实性 | 日期、数字、职位、技能级别和成果必须有来源。版面不够时删减低相关内容，不压缩事实边界。 |

## 二、固定页面几何

### 左栏

- 位置：`x = 0–70 mm`，宽 `70 mm`，高 `297 mm`。
- 背景：`#283446`；主要文字白色，次要文字 `#e2e8f0`。
- 内边距：上 `9 mm`、右 `7 mm`、下 `9 mm`、左 `8 mm`。
- 内容顺序固定：照片 → CONTACT → Disponibilité → LANGUES → COMPÉTENCES TECHNIQUES。
- 不把工作经历、教育正文或长段落放入左栏。

### 右栏

- 位置：`x = 70–210 mm`，宽 `140 mm`。
- 内边距：上下各 `9 mm`，左右各 `10 mm`；实际内容宽约 `120 mm`。
- 内容顺序固定：姓名与目标岗位 → PROFIL → EXPÉRIENCE PROFESSIONNELLE → PROJETS ACADÉMIQUES ET TECHNIQUES → FORMATION。
- 日期靠右，机构在左、地点在右；同一行内容必须基线对齐。
- 不改变左右栏顺序，不把 PROFIL 或 FORMATION 移到侧栏。

## 三、照片规范

- 使用 `个人资料/template/portrait.png`，只存在于个人工作区；公开 Skill 模板必须使用脱敏占位图。
- 宽度固定 `42 mm`，最大高度 `56 mm`，水平居中，顶部位于左栏内边距之后。
- 使用 `object-fit: contain`，完整显示原图并保持宽高比；禁止拉伸、压扁、裁切头顶或改变脸部比例。
- 照片下方间距约 `12 px`。
- 照片缺失或仍是 1×1 占位图时隐藏照片区域，不显示空白方框，也不生成虚构头像。

## 四、字体和文字层级

| 元素 | 字号 | 字重/样式 | 位置与用途 |
|---|---:|---|---|
| 姓名 | `26 pt` | `800`，颜色 `#283446` | 右栏最上方；全页最高层级。 |
| 目标岗位副标题 | `11 pt` | `500`，颜色 `#4d4d4f` | 姓名下方；允许自然换行，不缩小字体。 |
| 主分区标题 | `13.5 pt` | `800`、大写、字距 `0.8 px` | PROFIL、工作经历、项目、FORMATION；下方 `2 px` 深色线。 |
| 左栏标题 | `13 pt` | `800`、大写、字距 `0.8 px` | CONTACT、LANGUES、COMPÉTENCES TECHNIQUES；下方 `1.5 px` 半透明白线。 |
| 经历/项目标题 | `10 pt` | `700` | 职位或项目名称；不得整段全大写。 |
| 日期、机构、地点 | `10 pt` | 日期 `500`，正文常规 | 日期和地点右对齐，机构左对齐。 |
| PROFIL 与 bullets | `10 pt` | 常规；关键词可局部 `700` | 行高约 `1.32–1.4`。 |
| 联系方式、语言、技能 | `9.5–10 pt` | 标签可 `600–700` | 保证链接和电话号码清晰可读。 |

不得用连续大段粗体。粗体只用于标题、技能标签、可核实数字或确实需要快速识别的关键词。

## 五、内容容量与顺序

### 顶部身份区

- 姓名使用事实库中的确认写法。
- 副标题只写一个清晰的目标方向，例如 `Développeur logiciel · Data · IA appliquée`；不得堆砌超过三个不相干岗位。
- PROFIL 右上角显示合同路线和节奏：
  - Alternance：`Recherche d'alternance` + 已确认节奏；
  - Stage：使用已确认时长和区域；
  - 未确认时写待确认并停止生成正式版，不自行选择。

### PROFIL

- 2–4 行，约 45–75 个法语词。
- 顺序：当前身份 → 目标方向 → 2–3 组有证据的能力或经历。
- 不写公司专属动机，不写空泛性格词，不重复联系方式。

### 工作经历

- 默认保留 2 段最相关、已确认的职业经历。
- 每段 2–3 个 bullet；每个 bullet 优先控制在 1–2 行。
- bullet 结构优先为：场景/对象 → 个人动作或判断 → 可核实交付物或影响。
- 同一段经历避免重复列工具；工具应和实际动作放在同一句中。

### 项目

- 默认保留 2 个最相关项目。
- 每个项目 2 个 bullet，突出个人职责、技术接口和可核实结果。
- 团队成果必须标明团队边界；比赛名次可以写，但不能改成个人单项成绩。

### 教育

- 保留当前学历、学校、地点、起始时间、确认的平均分和与岗位相关课程。
- 当前模板保留 `Moyenne : 14,8/20`。
- 不把计划中的 Master 写成已入读，不同时展示互相冲突的毕业路线。

### 左栏内容

- CONTACT：电话、邮箱、GitHub、LinkedIn、Île-de-France；每项独立且可读。
- Disponibilité：与选定合同路线完全一致，最多 2–3 行。
- LANGUES：语言及确认级别，每项一行。
- COMPÉTENCES TECHNIQUES：4–5 组，每组以加粗类别开头；每组 1–2 行。技能必须在事实库或经历中有依据。

## 六、铺满一页时的调整顺序

内容不足或过多时按以下顺序处理，不允许 AI 任意改样式：

### 页面过空

1. 检查是否遗漏与目标岗位高度相关且已有证据的 bullet、交付物、技术接口或课程。
2. 将过度压缩的一行 bullet 补充为完整的“动作 + 对象 + 结果”，但不得加空话。
3. 在模板允许范围内恢复标准段间距和行高。
4. 仍有空白时保留适度留白；不得增加虚构技能、职责、数字或性格描述。

### 页面溢出

1. 删除与 JD 相关性最低的 bullet 或技能组。
2. 合并同一经历中的重复工具与动作。
3. 将 3 个 bullet 压缩为 2 个，保留个人贡献和结果。
4. 缩短 PROFIL 和课程列表。
5. 最后才在允许范围内微调间距；正文不得低于 `9 pt`，照片、栏宽和页面比例不得缩放。

禁止通过整体缩放 PDF、压扁照片、减小页面、隐藏文字、负边距或缩到不可读字号来满足一页。

## 七、模板内容替换规则

- `个人资料/template/resume.html` 是视觉母版，不能被岗位内容覆盖保存；每次复制到新的岗位输出目录后再替换。
- 只替换姓名、联系方式、可用性、目标岗位、PROFIL、经历、项目、教育和技能文字。
- 保留模板的 DOM 分区、CSS、颜色、栏宽、图标、照片规则和标题层级。
- 模板里的示例公司名、岗位名、日期和正文必须全部替换；生成器发现残留占位符或旧岗位内容时应失败。
- 对外文件名使用 `姓名-CV-公司-岗位.pdf`；不得包含 `test`、`draft`、`compressed`、`under3MB` 等内部标记。

## 八、最终验收清单

生成后必须同时检查 HTML、PDF 文本和 PDF 页面截图：

1. PDF 恰好 1 页 A4，背景色和图标正常。
2. 姓名、目标岗位、合同路线和可用性一致。
3. 所有日期、数字、职位、学校、技能和成果均可追溯到 claim-map 来源。
4. 没有旧公司名、旧岗位名、占位符、测试文字或内部状态词。
5. 照片完整、不变形、不裁切；公开模板不含个人照片。
6. 没有截断、重叠、孤立标题、跨栏、超出页面或过小文字。
7. 标题层级、左右对齐、分区线和 bullet 缩进一致。
8. 页面主体占用合理；若底部留白明显，确认已按“页面过空”顺序检查，且没有为了填满而编造内容。
9. 电话、邮箱和公开链接可读，文件名符合对外规范。
10. 机器检查通过后仍需目视检查；未目视确认的材料保持 `review-required`。
